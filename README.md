<h2>🛠️ Método 1: Restauración y Limpieza de Atributos</h2>
</div>
> 💡 Descripción: Ideal para quitar atributos ocultos, de sistema o de solo lectura que a veces dejan los virus o malwares en unidades USB o carpetas, facilitando su visualización y eliminación. 📁✨
> 
 * 💻 Abrir el Símbolo del Sistema (CMD):
   Presiona las teclas Windows + R, escribe cmd y presiona Enter (o abre CMD como administrador).
 * 📂 Ubicarse en la unidad o carpeta afectada:
   Escribe la letra de tu unidad (por ejemplo, E: o F:) y presiona Enter.
 * ⚡ Ejecutar el comando de limpieza:
   Copia y pega el siguiente código en la consola:
   attrib -s -h -r /s /d *.*

 * 🔍 Resultado:
   Con este comando removerás los atributos de sistema (-s), oculto (-h) y de solo lectura (-r) en todos los archivos y subcarpetas (/s /d *.*), dejándolos limpios. 🧹

<h2>🛡️ Método 2: Verificación de Integridad del Sistema</h2>
</div>
> 💡 Descripción: Permite escanear y reparar archivos de sistema dañados o corruptos en Windows utilizando la herramienta oficial System File Checker. ⚙️🔒
> 
 * 🔍 Buscar la consola:
   Escribe cmd en la barra de búsqueda de Windows.
 * ⚡ Abrir como Administrador:
   Haz clic derecho sobre Símbolo del sistema y selecciona "Ejecutar como administrador" 🖥️✨.
 * ⌨️ Escribir el código de escaneo:
   Copia y pega el siguiente comando en la ventana negra y presiona Enter:
   sfc /scannow

 * ⏳ Esperar el resultado:
   El sistema empezará a verificar la integridad de todos los archivos protegidos y reparará cualquier archivo corrupto encontrado automáticamente. 🛠️🔍

<h2>⚡ Método 3: Escaneo de Seguridad con PowerShell</h2>
</div>
> 💡 Descripción: Ejecuta un análisis antivirus completo o rápido utilizando las herramientas nativas integradas en Windows a través de PowerShell. 🦠🛡️
> 
 * 💻 Abrir PowerShell como Administrador:
   Busca PowerShell en el menú de inicio, haz clic derecho sobre él y selecciona "Ejecutar como administrador" 🛡️✨.
 * ⌨️ Escribir el código de análisis:
   Copia y pega el siguiente comando en la consola y presiona Enter:
   Start-MpScan -ScanType FullScan

   > 💡 Nota: Si prefieres un análisis rápido en lugar de uno completo, puedes cambiar el parámetro al final por QuickScan (Start-MpScan -ScanType QuickScan). 🔍⚡
   > 
 * ⏳ Esperar el diagnóstico:
   El sistema iniciará el escaneo de seguridad a fondo para detectar y limpiar cualquier amenaza en el equipo. 🧹🚀

<h2>🧽 Método 4: Herramienta de Eliminación de Software Malintencionado</h2>
</div>
> 💡 Descripción: Ejecuta la herramienta de diagnóstico de Windows mediante una ventana rápida de ejecución para buscar y eliminar software malintencionado del equipo. 🔍💻
> 
 * ⌨️ Abrir la ventana Ejecutar:
   Presiona las teclas del teclado Windows + R al mismo tiempo para que se abra la ventana flotante de ejecución 🪟✨.
 * 🔤 Escribir el comando:
   En el cuadro de texto que aparece, escribe la siguiente palabra y presiona Enter o haz clic en Aceptar:
   mrt

 * 🧹 Ejecutar la herramienta:
   Se abrirá el asistente oficial de Microsoft (MRT) para guiarte en el análisis y limpieza del equipo de manera gráfica y sencilla. 🚀🎉
